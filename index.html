CMIP6 · THOR ensemble results

THOR Regime Atlas

THOR's 50-member neural-network ensemble assigns each ocean grid point to one of six dynamical regimes from Sonnewald & Lguensat (2021). These plots cover seven CMIP6 models across the historical, 1pctCO2, and abrupt-4xCO2 experiments in two basins, the Kuroshio Extension and the North Atlantic. They include regime maps, SHAP and LRP feature attributions, model sea surface height anomaly beside satellite altimetry, and a comparison against THOR run on the ECCO state estimate.

    Caveats

    • ECCO's mask blanks some ocean: the Sea of Japan, most of the Sea of Okhotsk, and the East China Sea shelf. Small islands such as the Azores, Madeira, and the Faroes show up as coarse blocks. The mask comes from ECCO's own preprocessing (a budget-residual filter combined with the open-water fraction), which isn't included in the DNN4Cli code.
    • Model coastlines look wider than ECCO's. THOR's inputs use spatial gradients, which are undefined next to land, so each model loses about 9% more cells than its bathymetry mask alone removes.
    • Class numbers were matched to regime names from the Step 1 clustering data, using term magnitudes, term signs, and geography against Sonnewald & Lguensat (2021). The original code doesn't store this mapping.
    • SHAP uses fastshap's KernelExplainer with a 100-point background sample, run separately on each of the 50 ensemble members, at every ocean point of each model's native grid.
    • LRP uses the ε-rule (ε = 0.25 × the standard deviation of each layer's pre-activations). It's computed over the whole domain and cropped to each basin, so the values match a whole-domain run.
    • The SSH anomaly plots follow GCOOS's method with a 2012–2014 reference period, the only overlap between this altimetry product (from 2012) and CMIP6 historical (to 2014). Both panels share the observed reference mean by construction, and a free-running model's eddies aren't in phase with the real ocean, so the useful comparison is amplitude and spatial scale, not where individual features sit.
    • E3SM-1-0 publishes its ocean output already regridded to 1°. The other models are plotted on their native curvilinear grids.
